# Edward S. Vidal | BSIT Portfolio

Personal portfolio website for IT support, networking and data analysis.

**Live site:** https://warden64595.github.io/project-personal-portfolio/

## What is on the site
- Professional profile, education and experience, skills with evidence, and a one-page resume (PDF download)
- Project 2: Ticket Analytics Dashboard (SQL and Excel), with its own repository: https://github.com/Warden64595/ticket-analytics-dashboard
- Five documented troubleshooting cases, a SQL injection case study, and an AI usage log
- Interview preparation, career plan, certificates, reflection and a final portfolio checklist
- Extras written in JavaScript: IPv4 subnet calculator, certificate gallery, dark and light mode, 3D globe, card tilt and a 3D skills cube

## Technologies
HTML, CSS, JavaScript and Bootstrap 5 (loaded from a CDN, so an internet connection is needed).

## File structure
```
project-personal-portfolio/
├── index.html                  page content (all sections)
├── css/style.css               all styles, including the dark theme and 3D effects
├── js/main.js                  all behavior: theme, effects, subnet calculator, gallery, checklist
├── assets/
│   ├── photo.png               hero photo (background removed)
│   ├── resume.pdf              downloadable resume
│   └── case1-workstation.jpg   evidence photo for troubleshooting case 1
└── README.md
```

## Run it on your computer
Download or clone the repository and open `index.html` in a browser.

## Use of AI tools
AI tools helped me plan and write parts of the website code and text. I tested the site and corrected the content to match my real experience. The AI usage log on the site lists the tasks and how I verified them.
